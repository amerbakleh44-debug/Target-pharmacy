تطبيق صيدلية التارغيت — نسخة قابلة للتثبيت (PWA)

المحتويات:
- index.html: المتجر ولوحة الإدارة
- manifest.json: إعدادات التثبيت على الهاتف
- sw.js: تخزين واجهة التطبيق الأساسية مؤقتاً
- icons/: أيقونات التطبيق

مهم: لكي يظهر خيار تثبيت التطبيق، ارفع كل الملفات والمجلدات كما هي إلى استضافة تدعم HTTPS. فتح index.html محلياً من مدير الملفات أو Acode لا يكفي لتفعيل التثبيت وService Worker.

بعد رفعه على HTTPS، افتح رابط الموقع في Chrome على Android، ثم من قائمة ⋮ اختر Install app أو Add to Home screen.

المتجر يحتاج اتصال إنترنت لجلب المنتجات وتسجيل الدخول ورفع الصور وإرسال الطلبات. التخزين المؤقت لا يجعل قاعدة البيانات تعمل دون اتصال.
